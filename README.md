## GitHub Pages Setup

This repository already includes a root `index.html` entrypoint and a `gh-pages` branch.

In GitHub, enable Pages with:

1. Open `Settings > Pages`
2. Set `Source` to `Deploy from a branch`
3. Set `Branch` to `gh-pages`
4. Set folder to `/root`
5. Save

The public site will be:

`https://jinhyeokkrap.github.io/Glass-Review/`
