Updated: 2026-06-24

## Current Coverage Gap

The current image set has 20 brands and 312 front-view products. It is useful for mainstream optical silhouettes, but it is still weighted toward licensed luxury and Luxottica-group brands. For AI glasses product design, the next research wave should add more brands with distinct structure, bridge, hinge, rim, and wearable-device relevance.

## Recommended Next Collection Plan

1. Phase 2A: Add Priority A only, about 74 images. This fills the biggest construction/form gaps quickly.
2. Phase 2B: Add Korea/Japan brands, about 104 images. This is highly relevant for face-fit and fashion direction.
3. Phase 2C: Add 10-12 European independents, about 70 images.
4. Phase 2D: Add smart/AI glasses references separately, about 40-45 images, and tag them as hardware references rather than pure optical-form references.

The best next step is Phase 2A plus the Korean/Japanese group: roughly 170-180 new images, bringing the dataset to about 480-500 images with much better form diversity.
