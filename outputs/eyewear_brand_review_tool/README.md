# Eyewear Brand Review Tool

Open `index.html` to review the 300 eyewear references by brand.

- Brand sidebar: jump between brands
- Grid: click a frame to inspect it
- Detail panel: mark Pick, Hold, or Reject
- Detail image: click to open a large centered preview
- Score: 1 to 5
- Tags and notes: saved in the browser
- Export: download CSV or JSON of the current review state
- Picked JSON: download only picked frames
- Save Picks by Brand: choose a folder and copy picked images into `picked_by_brand/<brand>/`

Review state is stored in browser local storage on this machine.
